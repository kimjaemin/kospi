# 코스피 분석기

코스피 시가총액 상위 10개 기업과 코스피 지수를 일별·월별·연도별로 보는 프로그램입니다.

## 실행

Python 3.10 이상이 필요합니다.

- macOS: `코스피 분석기.app` 을 더블클릭하면 전용 창으로 열립니다. 창을 닫으면 프로그램도 끝납니다. 앱은 이 폴더 안에 둔 채로 쓰고, Dock에 끌어다 놓아도 됩니다.
- macOS(브라우저로 열기): `run.command` 를 더블클릭합니다. 처음 실행할 때 필요한 패키지를 설치하느라 1~2분 걸립니다.
- Windows: `run.bat` 를 더블클릭합니다.
- 직접 실행: `pip install -r requirements.txt` 후 `streamlit run app.py`

`run.command`, `run.bat`, 직접 실행은 브라우저에서 http://localhost:8501 이 열립니다. 전용 창은 `python gui.py` 로도 열 수 있습니다.

## 기능

- 시가총액 상위 10/20: 특정 날짜(일별), 각 월의 마지막 거래일(월별), 각 연도의 마지막 거래일(연도별) 기준 순위와 시가총액. 월별·연도별은 순위 변화 표도 함께 보여줍니다. 우선주 제외 옵션이 있습니다.
- 종목 지표: 종목별 사업분야(업종, 주요 제품)와 PER·PBR·EPS, 같은 업종의 평균 PER·PBR·EPS. 최신 값만 제공하며 과거 날짜를 골라도 최신 값이 표시됩니다.
- 코스피 지수: 일별·월별·연도별 시가·고가·저가·종가와 등락률, 차트.
- 모든 표는 CSV로 내려받을 수 있습니다.

## 데이터

- 시가총액: 한국거래소 전종목 시세를 모은 [marcap 데이터셋](https://github.com/FinanceData/marcap) (1995-05-02~). 코스피 일자별 상위 30종목만 `data/kospi_top30.parquet` 에 보관합니다.
- 종목 지표: 네이버 금융(업종 분류, PER·PBR·EPS·BPS)과 KIND 상장법인목록(주요 제품). `data/kospi_fundamentals.csv` 에 최신 스냅샷만 보관합니다. 업종 평균은 같은 업종의 코스피 보통주로 계산합니다(PER = 시가총액 합 ÷ 순이익 합, PBR = 시가총액 합 ÷ 순자산 합, EPS = 단순평균). 네이버가 표시하는 동일업종 PER은 코스닥을 포함하고 전일 종가 기준이라 값이 다를 수 있습니다.
- 코스피 지수: 네이버 금융 일별 시세(2014년 이전 구간은 FinanceDataReader로 보충). `data/kospi_index.csv` 에 보관합니다.
- 프로그램을 열 때 새 거래일이 있으면 자동으로 받아오고, 왼쪽의 "데이터 새로 받기" 버튼으로 직접 갱신할 수도 있습니다. 시가총액 데이터는 원본이 올라오는 데 하루 이틀 걸릴 수 있습니다.

## 아이폰·웹에서 보기

`docs/` 폴더는 설치 없이 브라우저에서 여는 웹앱이며 GitHub Pages로 공개됩니다: https://kimjaemin.github.io/kospi/

아이폰에서는 Safari로 위 주소를 연 뒤 공유 버튼 → "홈 화면에 추가"를 누르면 앱처럼 설치됩니다.

데이터는 GitHub Actions(`.github/workflows/update-data.yml`)가 평일 18:30과 매일 08:00(한국 시간)에 받아 `docs/data/` 를 다시 만듭니다. 직접 만들려면 `python scripts/update_all.py` 를 실행합니다.
